# Techtabs Online Simulation — Light Mode Design System

## Core Aesthetic & Principles
- **Theme Mode**: Crisp Light Mode (No dark backgrounds)
- **Vibe**: Clean, professional corporate simulation & executive decision engine with high clarity, precise data density, and soft subtle elevation.

## Color Palette
- **Page Background**: Light Slate (`#f8fafc`)
- **Container / Card Background**: Pure White (`#ffffff`)
- **Header / Navigation Bar**: Light Slate Header (`#ffffff`) with subtle bottom border (`#e2e8f0`)
- **Primary Accent**: Deep Indigo-Blue (`#2563eb`) for action buttons, active navigation items, and primary metrics
- **Secondary Accent**: Slate Blue (`#475569`) for subtle actions and secondary indicators
- **Primary Text**: Dark Slate (`#0f172a`)
- **Secondary Text**: Cool Gray (`#64748b`)
- **Border / Divider Line**: Soft Gray (`#e2e8f0`)
- **Status - Success / Profit Growth**: Emerald Green (`#059669`) with light green badge background (`#dcfce7`)
- **Status - Warning / Constraint**: Amber Gold (`#d97706`) with light amber badge background (`#fef3c7`)
- **Status - Danger / Deficit**: Crimson Red (`#dc2626`) with light red badge background (`#fee2e2`)

## Typography
- **UI Font Family**: Inter / Plus Jakarta Sans
- **Font Sizes**:
  - H1 / Page Title: 24px (Mobile) / 30px (Tablet/Desktop), Bold
  - H2 / Section Title: 18px (Mobile) / 22px (Tablet/Desktop), Semi-Bold
  - Metric Value: 24px - 32px, Extra-Bold
  - Body Text: 14px, Medium/Regular
  - Caption / Label: 12px, Medium

## Elevation & Roundness
- **Card Roundness**: 8px (`ROUND_EIGHT`)
- **Card Shadows**: Soft, subtle shadow `0 1px 3px 0 rgba(0, 0, 0, 0.05), 0 1px 2px 0 rgba(0, 0, 0, 0.03)`
- **Borders**: 1px solid `#e2e8f0`

## Responsive Layout Guidelines
- **Mobile (375-390px)**: Single-column vertical stacking, accordion decision sections, sticky bottom CTA bar.
- **Tablet / iPad (768-834px)**: 2-column grid, split decision input and financial impact summary, mini-sidebar.
- **Laptop / Desktop (1280px)**: 4-column KPI grid, full navigation sidebar, multi-period comparative analytics table.
